## Open it in Snowsight

1. In Snowsight go to **Projects → Workspaces** (or **Worksheets**) and create a new SQL file
2. Paste the script in
3. Run each statement **one at a time**: place the cursor on it and press ++cmd+enter++ (Mac) / ++ctrl+enter++ (Windows)

!!! info "CoCo prompts"
    After each query there's a **CoCo prompt** box. Paste it into CoCo to have the AI write the same SQL.
    Compare its answer to the one in the script.
